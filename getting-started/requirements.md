# 📋 Requirements

Here are the requirements for running Laravel Like package in your environment. All the dependencies and environment requirements are listed here.

## Environment

- PHP **^8.2** (continuing through PHP 8.3, 8.4 and 8.5)
- [Composer](https://getcomposer.org/)

## Framework

- [Laravel](https://laravel.com/) **^11.0 | ^12.0 | ^13.0**

| Framework | PHP | Status |
| --- | --- | --- |
| Laravel 11 | 8.2 - 8.4 | ✅ Supported |
| Laravel 12 | 8.2 - 8.5 | ✅ Supported |
| Laravel 13 | 8.3 - 8.5 | ✅ Supported |

> **Note:** Laravel 13 requires PHP 8.3 or newer. If you use PHP 8.2, stay on Laravel 11/12 or upgrade your PHP version.

## Dependencies

- [illuminate/support](https://packagist.org/packages/illuminate/support) `^11.0 | ^12.0 | ^13.0`
- [illuminate/database](https://packagist.org/packages/illuminate/database) `^11.0 | ^12.0 | ^13.0`

All the dependencies are automatically installed when you install the package via Composer.
